# 项目方向

CIS 在强散射、多尺度条件下可能收敛缓慢。宏观合成方程提供一条加速路线，
但闭合、辅助系统与动力学离散的兼容方式并非唯一。本项目建立可复核的探索框架，
支持选择、配置、实现和组合通用迭代器、预条件器、低阶校正及领域方法。

加速的含义是在正确性要求满足后，相对 CIS 降低求解成本。
具体成本口径和“显著加速”的阈值由 C03/C04 决定。
已有方法的有效配置与组合也是成果；不要求 agent 发明原创算法。

第一阶段：灰度 PBTE 问题族中的方法探索、效率与所声明 regime 的鲁棒性。
当前稳态灰度线性 Callaway 后端是起点；参数域与离散选择等待 C01/C02。
第二阶段：向明确的 mode-dependent 模型迁移，评价正确性、适配成本与性能。
C07 独立待定，不阻塞第一阶段工程 smoke。

产出包括探索框架、方法及证据资产、服务研究的评测协议。
流程为配置 → 候选 → 冻结代码与配置 → 求解 → 独立检查与原始成本 →
分析成功/失败范围 → 保存证据 → 下一轮探索或迁移。

不以强模型必须失败、依赖特定知识才能通过、分数差异达到倍数、题目数量或
扩展第二种 kinetic physics 为成功条件。也不声称全域最优、所有 Kn 均加速、
灰度成功即非灰成功。方向修改需负责人明确决定，实验观察不能自动改写方向。
